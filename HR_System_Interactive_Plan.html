تفعيل نظام الموارد البشرية والرواتب (EnableHR)

يتحكم في إظهار شاشات وقوائم الـ HR في الصلاحيات والشريط الجانبي (Default: 0)

🛡️ مبدأ عدم تعارض النسخ القديمة (100% Backward Compatible):
  • العمود الجديد EnableHR BIT NOT NULL DEFAULT 0 في [Settings].[CompanySettings].
  • عندما تكون القيمة 0 لا تتأثر أي شاشات قديمة أو تقارير أو حسابات.
  • تظهر صلاحيات HR فقط إذا كانت القيمة 1.
